# 角色知识边界检查

把“事实是真的”和“角色知道这件事”分开维护，并追踪每次获知、误解、隐瞒和遗忘。

## 工作流

1. 为关键事实建立真值状态，并列出每个角色当前知道、相信、怀疑、误解或刻意隐瞒的内容。
2. 每次知识变化必须有渠道、时间、场景和证据；共同在场不自动等于听见或理解。
3. 检查对白、行动、计划和内心叙述是否使用了角色尚未获得的信息。
4. 区分作者向读者披露、视角人物获知和其他角色获知，防止叙事层级混淆。
5. 穿帮问题列出首次非法使用位置和最早可合法获得位置，比较补渠道、改台词或改顺序的最小方案。
6. 修订后复查相关角色后续所有决策，确认没有产生新的动机或信息矛盾。

## 输出合同

- 事实真值与角色知识矩阵
- 知识获得/误解/隐瞒事件
- 穿帮证据与影响章节
- 最小修复选项
- 修后级联复检

## 安全边界

- 原稿仍是权威来源；角色知识不能根据模型常识自动补齐。
- 证据不足时标记未知，不把读者知道的内容赋予角色。
- 不通过新增大段解释强行修复，优先最小渠道或表达调整。
- 写回必须经过作者确认和来源版本检查。

# 语义去 AI 味

目标是恢复具体叙事功能和作者自身节奏，不是执行关键词删除或套用另一种模板文风。

## 工作流

1. 先锁定本章事实、视角、人物目标、场景功能和作者风格指纹，禁止语言修订改变这些约束。
2. 标记抽象结论替代行动、重复解释、同义复述、万能转折、空泛情绪、整齐句式和意象堆叠。
3. 每项诊断说明它为什么削弱信息、动作、人物声音或节奏，不能只因为某个词常见就判定问题。
4. 优先删除无功能句，其次用可观察行动、感官选择或潜台词替代，保持必要的留白。
5. 对话按人物知识和关系位置修订，不能靠口头禅制造差异。
6. 修后对照风格指纹、事实和字数，确认没有过度压缩、过度文学化或新增设定。

## 输出合同

- 带证据的问题分类
- 每处文字的叙事功能判断
- 最小修订稿
- 事实/视角/风格回归结果
- 保留不改项与原因

## 安全边界

- 原稿仍是权威来源；修订不能改变人物动机、事件结果和伏笔功能。
- 不使用固定敏感词表冒充语义判断。
- 不模仿在世作者，不把模型常见表达自动等同于 AI 生成。
- 修订稿必须由作者审阅后才能写回。

# 伏笔生命周期管理

分别管理读者知道什么、角色知道什么和正文实际确认什么，让回收具有证据和剧情后果。

## 工作流

1. 区分伏笔、谜面、明示承诺、角色误解和纯氛围细节，避免把所有细节都登记成伏笔。
2. 每条记录包含埋设证据、预期作用域、涉及角色、读者/角色知识、重要度和最迟处理窗口。
3. 后续事件按强化、误导、部分揭示、回收、放弃或冲突更新，并保留章节证据。
4. 检查长期伏笔是否持续获得新信息；只有拖延没有推进时标记停滞。
5. 回收必须可回看、改变理解并产生选择或局面后果；只解释答案不算完整回收。
6. 跨卷迁移时保留来源卷和当前归属，修订上游后重算受影响状态。

## 输出合同

- 伏笔分类台账
- 生命周期事件与证据
- 读者/角色知识差
- 停滞、冲突和逾期清单
- 回收有效性检查

## 安全边界

- 原稿仍是权威来源；计划中的伏笔不能冒充已经埋设。
- 不凭模型推断补写未出现的线索。
- 不因长期未回收自动删除伏笔，作者保留叙事选择权。
- 任何正文修订都进入提案和复审流程。

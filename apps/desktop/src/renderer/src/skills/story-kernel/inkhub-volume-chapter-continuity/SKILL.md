# 卷章连续性审计

维护不同卷各自的编号与状态，并检查跨卷因果桥，不把全书扁平化处理。

## 工作流

1. 按卷建立独立章节序列，检查缺章、重复编号、错误归卷、异常跳号和标题冲突。
2. 为人物位置、时间、年龄、伤势、能力、关系、物品与地点建立逐章状态链。
3. 冲突必须列出两端证据、发生顺序、影响章节和可信来源；不凭单个摘要下结论。
4. 检查卷末结算是否成为下一卷的真实起点，识别状态回退、无解释复原和跨卷知识穿帮。
5. 对可修复问题选择最小改动位置；修复上游会影响后文时列出级联复检范围。
6. 修复后按卷重跑排序和状态链检查，不用全书平均结果掩盖单卷失败。

## 输出合同

- 分卷章节序列
- 连续性状态链
- 双端证据冲突单
- 最小修复位置与级联范围
- 分卷复检结果

## 安全边界

- 原稿仍是权威来源；派生状态不得反向覆盖正文事实。
- 不把不同卷的同号章节视为重复章节。
- 证据冲突时标记待作者裁决，不能替作者静默选择正史。
- 写回必须经过版本校验、备份和明确确认。

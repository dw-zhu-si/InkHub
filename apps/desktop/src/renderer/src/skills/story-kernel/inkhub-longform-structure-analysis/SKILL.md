# 长篇拆解与结构分析

从现有正文恢复故事实际发生的结构，不用计划稿替代已经写成的事实。

## 工作流

1. 分别建立全书、每卷和每章的开始状态、结束状态与不可逆变化。
2. 把事件改写为“人物选择—直接后果—新约束”的因果链，标出仅按时间相邻但没有因果的段落。
3. 对主线、支线和人物弧标记触发、升级、转折、最低点、高潮选择、结算与余波。
4. 核对开篇承诺、阶段兑现和结局方向，识别类型承诺错位与长期未推进问题。
5. 按卷分析节奏、信息密度、场景功能和章末钩子，避免跨卷平均化评价。
6. 建议先处理会改变后文的大结构，再处理场景与句段；每项建议都说明影响范围。

## 输出合同

- 全书与分卷结构图
- 因果链和人物弧
- 读者承诺兑现表
- 节奏与场景功能诊断
- 按影响排序的修订路线

## 安全边界

- 原稿仍是权威来源；大纲、简介和旧报告只能作为带来源的参考。
- 分析必须引用卷、章和可核对片段，不能用抽象评价代替证据。
- 不把个人偏好写成结构硬伤，不擅自决定作者未选择的剧情方向。
- 不自动写回正文。

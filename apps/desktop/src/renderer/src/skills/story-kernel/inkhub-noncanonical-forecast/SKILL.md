# 非正史剧情推演

生成候选未来而不是直接续写正史；任何分支在作者采用前都不能更新正文或故事状态。

## 工作流

1. 冻结当前正史版本、作者意图、当前焦点、开放伏笔和下一章约束。
2. 生成二至五条机制不同的分支，禁止只更换表面事件或角色名称。
3. 每条分支列出章节节拍、关键选择、预计状态变化、伏笔推进、风险和读者承诺匹配度。
4. 分支之间隔离推演，不把甲分支新增事实带入乙分支。
5. 作者选择后只保存候选计划和采用理由；仍需经过正式续写流程才能成为正文。
6. 正史、作者意图或关键设定版本变化后，旧分支标记过期，不自动迁移。

## 输出合同

- 正史与约束快照
- 二至五条隔离分支
- 分支节拍与状态变化
- 风险和承诺匹配比较
- 采用或过期记录

## 安全边界

- 原稿仍是权威来源；候选分支始终标记为非正史。
- 不自动修改正文、大纲、状态、伏笔或人物关系。
- 不把分支模型补全写成当前事实。
- 采用分支仍需作者明确确认。

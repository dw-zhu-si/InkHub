# 本书参考资料绑定

让资料只在被授权的书籍和任务中参与上下文，避免整个素材库无差别注入。

## 工作流

1. 导入时记录来源、标题、版本、许可或权属、文件位置和内容哈希。
2. 明确绑定到书籍、卷、角色或全局，并声明用途：事实参考、创意素材、风格约束、禁区或写作规范。
3. 把资料切分为保留来源位置的检索单元，原文件仍是权威版本，索引可重建。
4. 根据当前任务检索最相关段落，返回来源、位置、用途和匹配理由，不全文塞入上下文。
5. 正文与资料冲突时分别展示，不允许资料静默覆盖已经写成的正史。
6. 解绑、版本变化或来源缺失时使相关检索结果失效，并标记受影响任务。

## 输出合同

- 资料清单与来源版本
- 书籍/卷/角色/用途绑定
- 带位置的检索片段
- 冲突和失效提示
- 使用记录

## 安全边界

- 原稿仍是权威来源；参考资料不能自动成为故事正史。
- 不访问未登记路径、网络或外部服务。
- 不复制凭证、私密配置和无关个人资料。
- 许可证或权属不明的资料只允许本地参考，不标记为可分发资产。

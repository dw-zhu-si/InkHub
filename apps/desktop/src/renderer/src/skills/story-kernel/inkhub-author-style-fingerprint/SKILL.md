# 作者风格指纹

只从作者授权的自有作品提取可解释统计与技法特征，不复制第三方作者的可识别表达。

## 工作流

1. 明确样本作品、卷章范围、语言、视角和是否属于稳定成稿，排除提示词、报告和代写文本。
2. 统计句长分布、段落长度、对话比例、叙述距离、语域、标点、意象密度和常用转场。
3. 提取角色声线与场景类型差异，避免用全书平均值抹平人物和叙事阶段变化。
4. 把特征分成必须保持、可变范围和偶发习惯，并为每项保存样本证据。
5. 检测新章节偏移时说明偏移程度、上下文原因和是否真的影响阅读，不机械追求一致。
6. 更新样本后生成新版本，不静默改写旧指纹与历史报告。

## 输出合同

- 样本清单与版本
- 可解释风格指标
- 角色/场景差异
- 必须保持与可变范围
- 偏移证据和修订建议

## 安全边界

- 原稿仍是权威来源；风格指纹是辅助约束，不凌驾于剧情与人物事实。
- 不以在世作者或未经授权作品的可识别文风为目标。
- 不保存无必要的整段语料副本，证据只保留最小可核对范围。
- 不把统计差异自动判定为质量问题。

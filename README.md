# 墨枢 · InkHub

本地优先的 AI 小说创作、阅读与作品管理桌面应用。

此仓库仅用于分发经验证的安装包、版本说明和许可证，不包含开发源码或原项目 Git 历史。

## 下载

[查看正式 Release](https://github.com/dw-zhu-si/InkHub/releases)

0.3.0 正式资产适用于 Apple Silicon Mac（arm64）。请阅读 Release 的安装说明、已知限制及 SHA-256 校验文件。Windows 与 Intel Mac 不包含在本次正式下载中。

## 核心工作流

导入本地小说目录 → 按卷逐章阅读与检索 → 质检 → AI 生成修复稿 → 作者审阅 → 单独确认写回。

AI 能力通过用户自行配置的本机 ModelHub 使用；调用可能计费，输出需要人工审阅。应用不附带模型账户、额度或 ModelHub 安装程序。

## 许可与支持

InkHub 基于 Apache-2.0 授权的 [DeepWrite](https://github.com/swjybky/deepwrite) 修改，采用独立品牌，不代表上游认可或背书。许可证与第三方声明见每个 Release 的随附文件。

[提交问题](https://github.com/dw-zhu-si/InkHub/issues) 时请勿包含小说全文、密钥、数据库、个人路径或其他敏感内容。

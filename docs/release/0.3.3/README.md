# InkHub 墨枢 0.3.3 发布资料

- 营销版本：0.3.3；Mac App Store 构建号：3。
- 本目录是公开文案候选，构建与发布结果必须以实际门禁和外部状态为准。
- 既有 0.3.2 资产不覆盖；本地 Windows 测试包不作为本轮公开正式资产。

## 此版本的新增内容

• 新增选题档案与作品闭环：记录读者承诺、核心冲突和证据，预填创建书籍、关联已有作品，并将本书选题资料用于创作参考。
• 新增长篇结构与主线/章卡正文检查，区分空白、占位、已填写与截断待查，支持分批检查和取消。
• 新增作品体检，统一查看原稿、全文索引、故事事实和章节摘要的新鲜度，明确缺失、陈旧与部分覆盖。
• 新增可编辑、启停及按短篇/剧本/长篇设置范围的作者偏好，用于后续适用的 AI 创作请求。
• 完善创作上手向导、续作检查点，以及未保存草稿、存储异常、版本变化与作品打开失败的保护。
• 更新桌面运行时与依赖安全维护版本，按需加载提案审阅与子智能体记录面板，减小打开工作区时需要加载的脚本体积。

已填写不代表文学质量或事实准确性通过。AI 功能需要作者主动执行并使用自己的模型服务，可能产生供应商费用；本地资料管理与检查不自动发起模型调用。
